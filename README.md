# Fan's Birthday Surprise ♡

A cream-toned interactive birthday website made for Fan.

## Preview
After enabling GitHub Pages, the site will be available at:
https://fqqq1209.github.io/fan-birthday-surprise/

## Files
- `index.html` — the complete interactive birthday website.
- `photos/` — add the personal photos referenced by the page.
- `music.mp3` — optional background music file; place it beside `index.html`.

## Add your photos
Create a folder named `photos` in the repository and upload these files with these exact names:
- `his-life.jpg`
- `time1.jpg`
- `time2.jpg`
- `time3.jpg`
- `time4.jpg`
- `time5.jpg`

The page includes visual fallbacks when photos are not present. The current source ZIP did not contain the actual photo or music files, so they still need to be added separately.

## Enable GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Wait for GitHub Pages to finish deploying.
